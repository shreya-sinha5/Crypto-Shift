# Post-Quantum Modernized Cryptographic Codebase

This directory contains the **Quantum Lock** migrated codebase generated by **CryptoShift**.

It replaces all classical, quantum-vulnerable cryptographic primitives from `demo/legacy_code/` with **NIST FIPS Post-Quantum Cryptography** standards.

---

## 🛡️ Migration Comparison

|---|---|---|---|---|
| **Key Encapsulation** | RSA-2048 (PKCS#1 v1.5) | **ML-KEM-768** (Module-Lattice KEM) | **NIST FIPS 203** | Immune to Shor's Factoring |
| **Digital Signatures** | ECDSA (P-256), RSA-SHA256 | **ML-DSA-65** (Lattice Signatures) | **NIST FIPS 204** | Immune to Shor's Discrete Log |
| **Key Agreement** | DH MODP-2048, ECDH P-521 | **Hybrid X25519 + ML-KEM-768** | **RFC 9370** | Double protection against classical + quantum attacks |
| **Hashing Utilities** | Broken MD5, Deprecated SHA-1 | **SHA3-256, SHA3-512, SHAKE-256** | **NIST FIPS 202** | Keccak sponge construction, collision-resistant |
| **Bulk Session Cipher** | AES-256-CBC (unauthenticated) | **AES-256-GCM** (authenticated AEAD) | **NIST SP 800-38D** | 128-bit quantum security against Grover's algorithm |
